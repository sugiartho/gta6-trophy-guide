Trophy Trail is an offline web app that guides and tracks all 55 PlayStation 5 trophies of Grand Theft Auto VI: the official list with saved progress, filters and a spoiler setting, a roadmap to the platinum, the missable trophies flagged, and a guide to each trophy in its own words that cites its sources. It works entirely offline from its own files — no network, no ads, no Rockstar artwork.

## Run it

```sh
python3 -m http.server 8080 --directory app
```

Then open http://localhost:8080 in a desktop browser.
